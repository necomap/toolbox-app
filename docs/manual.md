# 個人事業主の道具箱 ユーザーマニュアル

https://toolbox.lucke.jp

フリーランス・個人事業主のための無料ツール集です。会員登録は要りません。パソコンでもスマホでも使えます。

---

## はじめに知っておくこと

- **入力した内容は自動で保存されます。** 保存先は、お使いのブラウザの中だけです。運営者のサーバーには送られません。
- 次に同じブラウザで開くと、前回の入力が残っています。
- **ほかのパソコンやスマホとは共有されません。** ブラウザの履歴やサイトデータを消すと、保存内容も消えます。大事なものはPDFやCSVで保存しておいてください。
- 計算結果は**目安**です。最終的な税額や手続きは、国税庁・自治体の案内や税理士などで確認してください。
- 画面上のメニューから、ほかのツールにいつでも移れます。

## 1. 源泉徴収 逆算
**こんなときに**：「振込額をちょうど10万円にしたい。いくらで請求すればいい？」

1. 上で「手取り → 請求額（逆算）」か「請求額 → 手取り」を選ぶ
2. 金額を入れる
3. 消費税（10%を加算／8%を加算／加算しない）と、源泉徴収のあり・なしを選ぶ
4. 請求額・消費税・源泉徴収税額・振込額がすぐ表示される

- 源泉徴収は、請求書で消費税を分けて書く前提で、**税抜金額**に対して計算します。取引先が税込金額で計算している場合は結果が変わります。
- 端数を切り捨てる関係で、振込額が目標より数円多くなることがあります。

## 2. 請求書・見積書・納品書
**こんなときに**：インボイス対応の請求書をすぐ作ってPDFで送りたい

1. 「作成する書類」で請求書・見積書・納品書を選ぶ
2. 「発行者（あなた）」に屋号・氏名、登録番号（T＋13桁）、住所・連絡先、振込先を入れる（**次回からは入力済み**）
3. 請求先・請求番号・発行日・支払期限・件名を入れる
4. 明細に品目・数量・単価（税抜）・税率を入れる。行は「＋ 行を追加」で増やせる
5. 源泉徴収を差し引く場合は「差し引く」を選ぶ
6. 下のプレビューで確認し、「PDFで保存・印刷」を押す
7. 印刷画面の送信先（プリンター）で「PDFに保存」を選んで保存する

- 次の書類を作るときは「新規作成（明細をクリア）」を押します。発行者の情報は残ります。
- 登録番号が空欄だと、適格請求書（インボイス）になりません。免税事業者の方はそのままで問題ありません。
- 見積書にすると「支払期限」が「有効期限」に変わり、振込先は表示されません。

## 3. 納税積立カレンダー
**こんなときに**：税金の支払いで慌てないよう、毎月いくら取り分けておけばいいか知りたい

1. 前年の確定申告書や、自治体から届いた納税通知書を手元に用意する
2. 所得税（前年の納税額・今年の見込み）、住民税、国民健康保険（年額と納付回数）、個人事業税、消費税、国民年金（月額）を入れる。わからない項目は空欄でかまいません
3. すでに取り分けてあるお金があれば「いま取り分けてある額」に入れる
4. **毎月の積立額**と、今月から12か月の支払予定・月末の積立残高が表示される

- 積立額は「どの月も残高が足りなくならない、いちばん少ない月額」です。単純に年額を12で割るより確実です。
- 前年の所得税が15万円以上だと、7月と11月に予定納税が入ります。
- 実際の期限は年や自治体によって違います。通知書で確認してください。

## 4. 家事按分
**こんなときに**：自宅兼事務所の家賃・光熱費・通信費を、どれだけ経費にできるか計算して根拠を残したい

1. 必要なら上の補助計算で按分率を出す
   - 面積：仕事で使う面積と住まい全体の面積
   - 時間：仕事で使う時間と全体の使用時間（週あたり）
2. 対象年を選ぶ
3. 一覧の経費ごとに、年間支払額・按分率（%）・根拠メモを入れる。行は「＋ 行を追加」で増やせる
4. 「経費にする額」と合計が表示される
5. 「CSVで保存」（Excelで開ける）か「印刷・PDF」で保存しておく

- 按分率に決まった正解はありません。**なぜその割合なのか**を説明できることが大切なので、根拠メモは必ず書いておきましょう。

## 5. 案件別 実質時給
**こんなときに**：どの仕事が本当に割に合っているか知りたい

1. 目標時給を入れる（任意）
2. 案件ごとに案件名・報酬（税抜）・経費・作業時間を入れる。案件は「＋ 案件を追加」で増やせる
3. 案件ごとの実質時給が棒グラフで表示される。目標に届かない案件は色が変わる

- 作業時間には、打ち合わせ・メール・修正・請求などの時間も含めると、実態に近い数字になります。

## 6. 消費税 納税額比較
**こんなときに**：原則課税・簡易課税・2割特例（3割特例）のどれが一番得か知りたい

1. 申告する年分を選ぶ
2. 簡易課税の事業区分を選ぶ（デザイン・IT・ライターなどのサービス業は第5種）
3. 1年間の売上（税込）と、消費税のかかる経費（税込）を入れる。8%の売上・経費があれば「軽減税率（8%）の…」を開いて入れる
4. 2年前の課税売上高を入れ、インボイス登録前は免税事業者だったかにチェックする
5. 3つの方法の納税額が並び、いちばん安いものが強調される

- 家賃（住宅）・人件費・保険料・税金など、消費税がかからない支出は経費に含めないでください。
- 簡易課税を使うには、原則として前の年のうちに届出が必要です。
- 2割特例は2026年分まで、2027・2028年分は3割特例（個人事業者のみ）になります。

## 7. 減価償却
**こんなときに**：パソコンや車を買った。今年いくら経費にできる？

1. 資産の種類を選ぶ（一覧にないものは「その他」を選んで耐用年数を入れる）
2. 新品か中古かを選ぶ（中古は、これまでの経過年数と月数も）
3. 取得価額、事業で使う割合、使い始めた年と月、青色申告か白色申告かを入れる
4. 選べる処理の方法（全額経費・一括償却・少額特例・定額法）と、毎年の償却額の表が表示される

- 青色申告なら、40万円未満（2026年4月1日より前に使い始めたものは30万円未満）は買った年に全額経費にできる特例があります。
- 耐用年数は主なものの目安です。正確には国税庁の耐用年数表で確認してください。

## 8. 収入印紙 判定
**こんなときに**：この領収書や契約書に印紙は要る？いくら？

1. 書類の種類を選ぶ
2. 書類に書く金額（税込）を入れる
3. 当てはまるものにチェックする（消費税を分けて書く／金額を書かない／営業に関しない受取書／PDFやメールで渡す）
4. 契約書の場合は、作る日を入れる
5. 必要な印紙の金額と、その理由が表示される

- 領収書は5万円未満なら不要です（消費税を分けて書けば税抜金額で判定）。
- **PDF・メール・電子契約で渡す場合は印紙は要りません。**
- 請求書・見積書・納品書には印紙は要りません。

## 9. ふるさと納税 上限額
**こんなときに**：自己負担2,000円で、いくらまで寄附できるか知りたい

1. 寄附する年と、青色申告特別控除の額を選ぶ
2. 1年間の売上と経費の見込みを入れる
3. 社会保険料（国保・国民年金など）、小規模企業共済・iDeCo を入れる
4. 配偶者・扶養親族がいれば入れる
5. 給与所得や医療費控除・生命保険料控除などがあれば「給与所得・生命保険料控除などがある場合」を開いて入れる
6. 寄附できる上限の目安が表示される

- 確定申告をする人は、ワンストップ特例は使えません。確定申告書にすべての寄附を書いてください。
- 上限ぎりぎりではなく、少し余裕をもって寄附するのがおすすめです。

## 10. ほかのアプリ
メニューの「ほかのアプリ」から、運営者が作っているほかのアプリ（食品表示ラベル、HACCPの衛生管理、テイクアウト予約、在庫管理、簿記、植物の健康診断、地域猫マップ）を見られます。カードを押すと、新しいタブでそのアプリが開きます。

## よくある質問

**Q. 入力した内容が消えました。**
ブラウザのサイトデータを消した、別のブラウザや別の端末で開いた、シークレット（プライベート）モードで使った、のどれかが考えられます。保存内容は、そのブラウザの中にしかありません。

**Q. スマホとパソコンでデータを共有できますか？**
できません。請求書はPDF、家事按分はCSVで保存して受け渡してください。

**Q. 計算結果が国税庁の計算と違う気がします。**
画面下の「お問い合わせ」から、入力した値とあわせてお知らせください。

**Q. PDFで保存するとレイアウトが崩れます。**
印刷画面で用紙サイズを「A4」、倍率を「100%（既定）」にしてください。ヘッダーとフッター（日付やURL）は、印刷画面の詳細設定でオフにできます。

**Q. 料金はかかりますか？**
すべて無料です。ページ内の広告やおすすめ商品のリンク（「PR」表示）の収益で運営しています。
