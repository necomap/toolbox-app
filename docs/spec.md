## 1. 目的と基本方針
- 個人事業主のお金まわりの「ちょっと面倒」を、登録なしですぐ片づけられるツールを1サイトにまとめる。
- **1ツール＝1ページ**。検索から各ツールのページに直接たどり着けるようにする。
- **入力データはブラウザの中だけ**に保存し、サーバーには送らない。サーバーに記録するのは、改善のための**匿名の利用状況**（ページ名・操作の種類・日付・ランダムな番号）だけ。
- 計算は国税庁・総務省などが公表している方法に従い、**自動テストで正しさを確認する**。結果はあくまで目安として表示する。

## 3. ツールの仕様

### 3.1 源泉徴収 逆算（gensen.html）
- **モード**：手取り→請求額（逆算）／請求額→手取り（順算）
- **入力**：金額、消費税（10%加算／8%加算／加算しない）、源泉徴収（あり／なし）
- **計算**
  - 源泉徴収税額＝税抜額が100万円以下なら 10.21%、100万円を超える部分は 20.42%。1円未満は切り捨て。
  - 源泉徴収の対象は**税抜金額**（請求書で消費税を分けて書く前提）。
  - 振込額＝税抜額＋消費税（1円未満切り捨て）−源泉徴収税額
  - 逆算は「振込額が目標以上になる、いちばん小さい税抜額」を二分探索で求める。端数の切り捨てのため、目標より数円多くなることがある。

### 3.2 請求書・見積書・納品書（invoice.html）
- **書類の種類**：請求書／見積書／納品書。見積書では「支払期限」を「有効期限」と表示し、振込先は出さない。
- **入力**：屋号・氏名、登録番号（T＋13桁）、住所・連絡先、振込先、請求先と敬称（御中／様）、請求番号、発行日、支払期限、件名、明細（品目・数量・単価〔税抜〕・税率10%/8%）、源泉徴収の有無、備考
- **インボイス対応**：税率ごとの合計と消費税額を表示。消費税は**税率ごとに1回**計算し、1円未満を切り捨てる。登録番号が空欄なら「適格請求書にはなりません」と注意を出す。
- **出力**：プレビューをA4（余白15mm）で印刷。ブラウザの印刷画面で「PDFに保存」を選ぶとPDFになる。「新規作成」で明細だけ消す（発行者の情報は残る）。

### 3.3 納税積立カレンダー（nouzei.html）
- **入力**：所得税の前年納税額と今年の見込み額、住民税の年額、国民健康保険の年額と納付回数（10回／12回／8回）、個人事業税の年額、消費税の年額、国民年金の月額、いま取り分けてある額
- **支払月**

| 項目 | 支払月 |
|---|---|
| 所得税の予定納税 | 前年の納税額が15万円以上なら、7月と11月に前年の3分の1ずつ（100円未満切り捨て） |
| 所得税の確定申告 | 3月（今年の見込み額から予定納税分を引いた額） |
| 住民税 | 6・8・10・翌1月の4回（端数は1期にまとめる） |
| 国民健康保険 | 10回：6月〜翌3月／12回：4月〜翌3月／8回：7月〜翌2月（端数は1期にまとめる） |
| 個人事業税 | 8月・11月の2回 |
| 消費税 | 3月 |
| 国民年金 | 毎月 |

- **毎月の積立額**：今月から12か月のあいだ、**どの月の月末残高もマイナスにならない最小の月額**（100円単位で切り上げ）。あわせて12か月の支払合計と単純な月平均を表示する。

### 3.4 家事按分（anbun.html）
- **按分率の補助計算**：面積（仕事で使う面積÷全体）、時間（仕事での使用時間÷全体の使用時間）
- **一覧**：経費名・年間支払額・按分率（%）・根拠メモを行ごとに入力し、経費にする額と合計を出す。初期の行は家賃・電気代・インターネット回線・携帯電話。
- **出力**：CSV（Excelで文字化けしないよう BOM 付き UTF-8、ファイル名は `家事按分_年.csv`）、印刷・PDF

### 3.5 案件別 実質時給（jikyu.html）
- **入力**：目標時給、案件ごとの案件名・報酬（税抜）・経費・作業時間
- **計算**：実質時給＝（報酬−経費）÷作業時間。目標時給に届かない案件は色を変えて棒グラフで表示し、目標に必要だった報酬額も出す。

### 3.6 消費税 納税額比較（shohizei.html）
- **入力**：申告する年分（2026／2027／2028／2029年分以降）、簡易課税の事業区分（第1〜6種）、税込の売上と経費（10%・8%）、2年前の課税売上高、インボイス登録前は免税事業者だったか
- **計算**（申告書と同じ順序）
  - 課税標準額＝税込売上×100/110（8%は100/108）、千円未満切り捨て
  - 売上の消費税（国税）＝課税標準額×7.8%（8%は6.24%）
  - 原則課税：仕入の消費税＝税込経費×7.8/110（8%は6.24/108）を差し引く
  - 簡易課税：売上の消費税×みなし仕入率（第1種90%〜第6種40%）を差し引く
  - 2割特例（2026年分まで）・3割特例（個人事業者のみ、2027・2028年分）：売上の消費税の2割（3割）を納める
  - 差引税額は百円未満切り捨て。地方消費税は国税の22/78（百円未満切り捨て）。原則課税で控除が多いときは還付として表示する。
- **判定**：いちばん安い方法を強調表示。2年前の課税売上高が5,000万円を超えると簡易課税、1,000万円を超えると2割・3割特例は使えないと表示する。

### 3.7 減価償却（genka.html）
- **入力**：資産の種類（主な耐用年数を選択式。「その他」は年数を直接入力）、新品／中古（中古は経過年数）、取得価額、事業で使う割合、使い始めた年月、青色／白色申告
- **選べる処理の判定**

| 取得価額 | 処理 | 条件 |
|---|---|---|
| 10万円未満 | 全額をその年の経費（消耗品費） | だれでも |
| 20万円未満 | 一括償却資産（3年で均等） | だれでも |
| 40万円未満 | 少額減価償却資産の特例で全額経費 | 青色申告のみ。2026年4月1日以後に使い始めたもの（それより前は30万円未満）。2029年3月31日まで |
| すべて | 定額法 | 個人事業主の原則 |

- **計算**
  - 定額法の償却率＝1÷耐用年数（小数第3位に切り上げ）。初年度は使い始めた月からの月割り。帳簿価額が1円になるまで償却表を作る。
  - 経費にする額＝償却額×事業で使う割合
  - 中古資産の耐用年数（簡便法）：法定耐用年数を過ぎていれば 法定耐用年数×20%、途中なら（法定耐用年数−経過年数）＋経過年数×20%。1年未満は切り捨て、最短2年。

### 3.8 収入印紙 判定（inshi.html）
- **書類の種類**：領収書（第17号文書）、請負契約書（第2号文書）、建設工事の請負契約書、継続的取引の基本契約書（第7号文書）、請求書・見積書・納品書・準委任の業務委託契約書
- **判定**
  - 電子データ（PDF・メール・電子契約）で渡す文書は印紙不要
  - 領収書：5万円未満は非課税。金額の記載がないものは200円。営業に関しない受取書は非課税
  - 請負契約書：1万円未満は非課税。金額の記載がないものは200円
  - 建設工事の請負契約書：2027年3月31日までに作成するものは軽減税率
  - 基本契約書：金額にかかわらず4,000円
  - 請求書・見積書・納品書、準委任の契約書：課税文書ではない
  - 消費税額を分けて書く場合は、税抜金額（税率10%）で判定する
- 税額表は国税庁「印紙税額一覧表」にもとづく。

### 3.9 ふるさと納税 上限額（furusato.html）
- **入力**：寄附する年（2026／2027）、青色申告特別控除（65万／55万／10万／なし）、売上、経費、社会保険料、小規模企業共済・iDeCo、配偶者控除の対象の配偶者の有無、扶養親族（一般・特定・老人の人数）、事業以外の所得、その他の所得控除、生命保険料控除（所得税・住民税）
- **計算**
  - 事業所得＝売上−経費−青色申告特別控除。合計所得＝事業所得＋事業以外の所得
  - 所得税の基礎控除：2026・2027年分は合計所得489万円以下で104万円、655万円以下で67万円、2,350万円以下で62万円、それを超えると段階的に縮小。住民税の基礎控除は43万円（2,400万円超から縮小）
  - 配偶者控除・扶養控除・生命保険料控除（所得税12万／住民税7万が上限）を反映
  - 住民税所得割＝課税所得×10%−調整控除（百円未満切り捨て）
  - **上限額＝住民税所得割×20%÷（90%−所得税率×1.021）＋2,000円**（総務省の計算式）
  - 2027年以降の寄附は、特例控除額（住民税所得割×20%の部分）の上限を193万円とする
- 障害者控除・寡婦控除・ひとり親控除・配偶者特別控除、所得税の税額控除は考慮しない。住民税は標準税率（10%）で計算する。

### 3.11 データのバックアップ（backup.html）
- **書き出し**：localStorage の `dougubako:` で始まるデータをすべて集め、JSON ファイル `dougubako-backup-YYYYMMDD.json` として保存する。中身は `{app:'dougubako', version:1, exportedAt:日時, data:{ツール名: 保存内容}}`。前回の書き出し日時を `dougubako-meta:lastBackup` に記録して表示する。
- **読み込み**：ファイルを選ぶと、書き出し日時と含まれるツールを表示する。「上書きして読み込む」を押すと、今の `dougubako:` データを消してからファイルの内容を書き込む。`app` が `dougubako` でないファイルは受け付けない。
- **消えにくくする設定**：ボタンを押したときだけ `navigator.storage.persist()` を呼び、ブラウザにデータの自動削除をしないよう求める（Firefox は確認が出るため、自動では呼ばない）。
- 検索エンジンには載せない（`noindex`）。フッター・トップページからリンクする。

### 3.12 匿名の利用記録
- `assets/common.js` の `Track` が、ページを開いたときなどに `/api/event` へ `{t: ページ名, e: 操作, v: ランダム番号}` を送る（`sendBeacon`）。**入力内容は送らない。**
- ランダム番号は端末ごとに1回作り、`dougubako-meta:vid` に保存する（16桁の16進数）。
- 操作の種類

| 操作 | 送るタイミング |
|---|---|
| `view` | ページを開いた |
| `use` | ツールのページで最初に入力した（＝使った人） |
| `print` | 印刷・PDF保存の画面を開いた |
| `csv` | 家事按分の CSV 保存 |
| `backup` / `restore` | バックアップの書き出し／読み込み |
| `amazon` | Amazon のおすすめリンクを開いた |
| `app:アプリ名` | ほかのアプリ一覧からアプリへ移動した |

- サーバーは「日付（日本時間）・ページ・操作・ランダム番号」の組み合わせを1行だけ保存する（同じ日の同じ操作は1回と数える）。IP アドレスは保存しない。
- 他サイトからの送信、知らないページ名・操作は受け付けない。
- 記録しない場合：ローカル（localhost）での動作確認中、管理画面で「この端末を集計に含めない」にした端末。

### 3.13 管理画面（admin/）
- **ログイン**：パスワードは Cloudflare の環境変数 `ADMIN_PASSWORD`（8文字以上）。コードには書かない。ログインすると、署名付きの Cookie（HttpOnly・Secure・SameSite=Strict、7日間有効）を発行する。パスワードを変えると、古い Cookie は使えなくなる。同じ回線から1時間に10回失敗するとロックする。
- **道具箱**：期間（7日・30日・90日・1年）を選び、サイト全体とツールごとの「見た人・使った人・利用率」、印刷・CSV・Amazon の人数、日別の折れ線グラフを表示する。人数は端末の数で、期間内の重複は除く。
- **アプリ**：`server/apps.js` の一覧ごとに、登録ユーザー数・7日／30日以内に利用した人数・30日以内の新規登録・月別の新規登録（12か月）・データ件数を表示する。外部への問い合わせは10分間キャッシュする（「アプリの数字を取り直す」で再取得）。1つのアプリが失敗しても、ほかは表示する。
  - **Firebase**：読み取り専用のサービスアカウント（Firebase Authentication 閲覧者・Cloud Datastore 閲覧者）の鍵を、環境変数 `FB_アプリ名` に入れる。ユーザーは Authentication の REST API（`accounts:batchGet`）、件数は Firestore の集計クエリ（`runAggregationQuery`）で取る。「利用」は最終ログインまたはトークン更新の日時で判定する。
  - **Supabase**：データベースの集計専用関数 `admin_app_stats(p_token)` を呼ぶ（`docs/sql/`）。関数は数字だけを返し、合言葉が合わなければ何も返さない。合言葉は環境変数 `SB_アプリ名_TOKEN`、データベース側はハッシュだけを保存する。

## 4. 収益化まわり

### 4.1 Amazonアソシエイト
- トラッキング ID：`lucketool-22`（`SITE.amazonTag`）
- 各ツールページに「この作業に役立つ本・グッズ（Amazon）」枠を出す。リンクは Amazon の**検索結果ページ**（`https://www.amazon.co.jp/s?k=キーワード&tag=lucketool-22`）。商品の売り切れでリンク切れにならず、価格を表示しないので規約上も安全。
- リンクには `rel="sponsored noopener"` を付け、枠に「PR」と表示する（ステマ規制への対応）。
- フッターとプライバシーポリシーに、規約で求められるアソシエイトの表記を載せている。
- おすすめの中身は `assets/common.js` の `AMAZON`（ページ名 → [表示名, 検索キーワード] の一覧）で変える。

### 4.2 広告・その他のアフィリエイト（予定）
- `<div class="ad-slot">` に AdSense のコードを入れると、自動で表示される。
- `<div class="aff">` に ASP（A8.net・もしもアフィリエイト等）のリンクを入れると、自動で表示される（会計ソフト・電子契約などの紹介用の文言は設置済み）。

## 5. 運用

### 5.1 更新して公開する手順
1. フォルダ内のファイルを直す
2. GitHub Desktop で「Commit to main」→「Push origin」
3. 1〜2分で Cloudflare Pages が自動で公開する

### 5.2 ほかのアプリを追加・削除する
`assets/apps.js` の `APPS` に1行足す（消す）。

```js
{ name:'アプリ名', url:'https://xxx.lucke.jp/', cat:'分類名', desc:'ひとこと説明', thumb:'' },
```

- 既存の分類名を書けばその見出しの下に入り、新しい分類名なら見出しが増える。
- 自前のサムネイルを使うときは画像を `assets/apps/` に置き、`thumb:'assets/apps/画像名.png'` と書く。

### 5.3 税制改正への対応（毎年）
12月の税制改正大綱と、3月の法律成立を確認する。変わっていれば `assets/tax.js` と `tests/tax.test.js`、README の「税制の前提」を直す。現在の前提は次のとおり。
- 消費税：2割特例は2026年分まで、3割特例は2027・2028年分（個人事業者のみ）
- 減価償却：少額減価償却資産の特例は、2026年4月1日以後に使い始めたものから40万円未満、2029年3月31日まで
- 印紙税：建設工事の請負契約書の軽減措置は2027年3月31日作成分まで
- ふるさと納税：所得税の基礎控除は2026・2027年分が104万／67万／62万円の3段階。2027年以降の寄附は特例控除額の上限193万円
